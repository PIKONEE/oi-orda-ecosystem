## Что это за продукт

- **Название / slug:** `Умный словарь` / `smart-dictionary`
- **product_id:** `2` (реестр ECOSYSTEM.md §7)
- **Архетип:** `A (WebView)`
- **Платформы:** Windows + Android, активация по ключу
- **Языки интерфейса:** RU + KZ (полный перевод)
- **Вариант:** `0 = english` (английский язык; другие языки — будущие варианты)

## Что делает продукт

**Инструмент учителя для показа у доски/проектора** (не личный трекер).
База **2800+ английских слов** в 39 разделах, **7 групп**, уровни **A1–C2**.
Есть группа «Продвинутый (C1–C2)» из 6 разделов (академ. лексика, глаголы,
прилагательные, человек/характер, общество/идеи, формальные выражения). По
каждому слову: транскрипция (IPA), перевод RU/KZ и 3–5 примеров. Светлая тема,
крупный шрифт, чистый интерфейс. Уровень виден цветом плитки и тегом
(A1 зел. / A2 голуб. / B1 янт. / B2 крас. / C1 фиол. / C2 тёмно-фиол.); в разделе —
фильтр по уровню.

Сценарий: учитель открывает **раздел** (или находит слово поиском) → одним
кликом запускает **Карточки-урок** (большая карточка для класса: слово → клик →
перевод и примеры; навигация вперёд/назад/перемешать) или **Квиз** (3 типа
вопросов, включая «вставь слово»). Кнопка **«Скрыть перевод»** — опросить класс;
режим **«Выбрать слова»** — собрать карточки/квиз из конкретных слов.

> Намеренно **без** личной статистики, прогресса «изучено/к повторению» и SRS —
> это демонстрационный инструмент для урока, а не самообучение.

## Структура контента (всё в `content/`)

```
content/
├── index.html         ← точка входа (entry_html), вся разметка экранов
├── app.css            ← оформление (светлая тема, фон, типографика, адаптив)
├── app.js             ← вся логика: группы/разделы, поиск, выбор, карточки, квиз
├── locales/i18n.js    ← переводы RU/KZ (window.I18N) — единственный источник строк
├── assets/
│   ├── uk-flag.svg    ← флаг Британии (полупрозрачный водяной знак в герое)
│   ├── fonts.css      ← @font-face: Manrope (текст) + PT Serif (заголовки)
│   └── fonts/         ← m*.woff2 (Manrope) + ps-*.woff2 (PT Serif), вкл. KZ-кириллицу
└── data/
    ├── index.js       ← группы (window.DICT_GROUPS) + разделы (window.DICT_CATS)
    └── cat_*.js       ← словарь по разделам, каждый файл делает window.WB.push(...)
```

**Оформление: академический стиль** (вдохновлён Vocabulary.com), светлая тема.
Тёмно-синяя (navy) шапка; глубокий сине-градиентный **герой-баннер** с серифным
заголовком, подзаголовком и крупным поиском; внутри героя — **полупрозрачный
флаг Британии** (`assets/uk-flag.svg`, `mix-blend-mode:screen`, в `.hero::after`).
Заголовки — **PT Serif** (`--serif`), текст — **Inter**; оба встроены локально
(офлайн), покрывают казахскую кириллицу. Палитра приглушённая navy/blue (без
неоновых градиентов). Главная двухуровневая: группы → мини-разделы, цвет плитки =
уровень (A1/A2/B1/B2). Глобального фон-узора нет (контент на белых карточках).
**Все** карточки разделов — без эмодзи, с полупрозрачной линейной фон-иллюстрацией
справа и фейд-аутом (по одному `assets/cards/<catKey>.svg` на раздел; путь задаёт
`app.js:catTile` через inline `--card-img`; размер/позиция/фейд — в `.cat-img`).
Блок «Все слова» — белая карточка с navy-акцентом, SVG-иконкой и шевроном.
(История фона: плоский градиент — «скучно»; орнамент Морриса и буквенный узор —
сливались/мутно; выбран чистый академический вид + флаг только в герое.)

**Почему данные и переводы — это `.js`, а не `.json`:** оболочка грузит контент
по `file://`. Загрузка через `<script>` гарантированно работает и на Windows,
и на Android без проблем с fetch/CORS. Каждое слово — компактный позиционный
массив `[cat, level, word, ipa, ru, kz, [examples...]]`; `app.js` превращает их
в объекты и проверяет целостность (3–5 примеров, нет пустых полей).

## Как добавить слова

Добавь строки в нужный `content/data/cat_<раздел>.js` (формат — позиционный
массив выше) или заведи новый файл `cat_<новый>.js` + впиши категорию в
`content/data/index.js` и переводы её названия в `locales/i18n.js`. `app.js`
валидирует данные при загрузке и пишет в консоль оболочки (`core.log`) число
загруженных слов и любые проблемы.

## Железные правила (из шаблона)

1. **`_secret.py` НЕ ТРОГАТЬ** и не коммитить (сгенерирован `keygen embed 2`).
2. **Не писать свою оболочку / экран активации / лицензии** — всё в product-core.
3. **Защита включена всегда:** `skip_activation:false`, `anti_copy:true`,
   `flag_secure:true` в `product.json`.
4. **Двуязычность RU/KZ** во всём новом UI.

> ⚠️ `anti_copy:true` отключает выделение текста, контекстное меню и
> drag-and-drop в WebView. Поэтому весь UX — **на кликах** (без перетаскивания),
> поля ввода (`input`) при этом работают нормально.

## JS-мост к оболочке (одинаков на Win/Android)

```js
// window.core.getDeviceId() -> "A3F2..." (16 hex)
// window.core.getStatus()   -> '{"valid":true,"variant_id":0,"days_left":120,...}'
// window.core.activateKey(k) -> onActivationSuccess / onActivationError (рисует оболочка)
// window.core.log("...")     -> лог оболочки
```

Экран активации рисует оболочка. Контент мост `core.*` не требует (работает и в
обычном браузере); `initCore()` лишь подключается к логу оболочки, если она есть.

## Запуск и сборка

```bash
python main.py                 # запуск (нужен pip install -e product-core)
python -m build .              # Windows + Android
python -m build . --windows    # только Windows
```

Локальная проверка контента без оболочки: открыть `content/index.html` в
обычном браузере — приложение работает автономно (мост `core.*` опционален).
