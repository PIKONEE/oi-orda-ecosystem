# ∑ Математическая лаборатория · Математикалық зертхана

Десктоп-приложение для уроков математики: визуализатор графиков функций и
калькулятор вероятностей. Двуязычное (RU/KZ), работает офлайн. Часть экосистемы
**Oi-Orda** — собрано на ядре `product-core` (защита + активация по ключу).

`product_id = 5` · архетип A (WebView) · Windows + Android.

## Структура продукта

```
math_tools/
├── product.json     ← конфиг продукта (id, имя, защита)
├── _secret.py       ← секрет продукта (НЕ коммитить; keygen embed 5)
├── main.py          ← 2 строки: запуск оболочки product-core
├── assets/icon.svg  ← иконка (→ .ico при сборке)
└── content/
    └── index.html   ← весь продукт (HTML/JS/CSS, ноль зависимостей)
```

## Два режима запуска

| | Файл | Активация |
|---|---|---|
| **Десктоп (как у пользователя)** | `Запустить.bat` → собранный EXE | ✅ есть |
| **Превью для разработки** | `Превью без активации.bat` → `content/index.html` в браузере | ❌ нет |

> Активация живёт в оболочке `product-core`, а не в HTML. Поэтому в браузере её
> нет (удобно разрабатывать), а в собранном EXE — есть.

## Сборка десктоп-версии

Запускать из каталога **product-core** (там лежит билд-пакет). Контент шифруется,
создаётся установщик Inno Setup:

```bash
pip install -e <путь_к_product-core>                  # один раз
python -m product_core.keygen init                    # один раз: ecosystem.keys (БЭКАП!)
cd <путь_к_product-core>

python -m build D:\math_tools --windows
#   → builds\windows\Mathtools\Mathtools.exe (~45 МБ)  и  Mathtools-Setup-1.0.0.exe (~20 МБ)
```

**Движок** задаётся в `product.json → "engine"`:
- **`webview2`** (по умолчанию у math-tools) — системный Edge WebView2, как WebView
  на Android. Бандл **~45 МБ**, установщик **~20 МБ**. Нужен WebView2 на клиенте:
  встроен в Windows 11, есть почти на всех Windows 10; где нет — положи рядом с
  установщиком `MicrosoftEdgeWebView2RuntimeInstaller.exe`, он поставится сам.
- **`qt`** — встроенный QtWebEngine (Chromium внутри), полностью автономно, но
  бандл ~445 МБ. Флаг `--nuitka` (защита кода компиляцией) работает только с `qt`.

Внешний вид и активация одинаковы для обоих движков.

## Выдать лицензию клиенту

Клиент сообщает Device ID с экрана активации. Лицензия v4 (Ed25519) подписывается
вашим приватным ключом и несёт ключ контента — подделать нельзя:

```bash
python -m product_core.keygen genlicense 5 0 <client_id> --device <DEVICE_ID> --months 12 --note "Школа"
#   → строка вида OL1-…  — клиент вставляет её на экране активации
```

## Возможности

**📈 Графики функций** — ввод «как в тетради» (дроби столбиком, степени, корни),
матклавиатура (x², √, ∛, |x|, дробь, π, sin/cos/tg…), живой предпросмотр формулы,
до 8 функций, пан/зум, трассировка точки.

**🎲 Вероятности** — монета, кубик d2–d100, два кубика, карты, урна, рулетка; до
1 000 000 испытаний; диаграмма с теоретической отметкой, таблица, график закона
больших чисел.

Подробности для ИИ-ассистента — в `CLAUDE.md`.
