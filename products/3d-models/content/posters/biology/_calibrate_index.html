📍 Zone Calibrator — список моделей

Калибруй зоны для каждого плаката, затем вставь сгенерированный JSON в HTML.
Как пользоваться:
  1. Открой нужную модель кнопкой «Калибровать»
  2. В правой панели выбери зону (станет active)
  3. Кликни на 3D-модель в нужном месте — поставится точка-якорь
  4. Для удлинённых частей (позвоночник, кишечник) ставь 2-3 точки вдоль
  5. Курсор по модели снизу показывает к какой зоне отнесётся клик
  6. Кнопка Copy JSON — скопируй и пришли мне, я вставлю в плакат
Подсказки: можно вращать камеру (drag), масштабировать (scroll), Ctrl+Z — undo последней точки, ось X красная, Y зелёная, Z синяя.
